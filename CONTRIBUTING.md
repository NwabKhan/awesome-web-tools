# Contributing Guidelines

Thanks for taking the time to contribute to Awesome Web Tools.

This repository is a **curated list, not an open directory**. Meeting the minimum requirements does not guarantee inclusion. Submissions are reviewed for usefulness, quality, fit, duplication, and overall value to the collection.

## Before You Submit

Please check all of the following before opening a pull request:

- Search the existing list to make sure the tool is not already included.
- The tool must provide clear, practical utility.
- The tool must be usable from a web browser without requiring installation for its core functionality.
- Core functionality must be available for free.
- Optional paid upgrades are fine, but a free trial alone is not considered free access.
- The tool must not require account creation or login just to use its core functionality.
- The tool should be functional and reasonably maintained.
- The link should point directly to the usable tool whenever possible.
- Do not use affiliate, referral, or tracking links.
- The tool should not substantially duplicate functionality already well represented in the list.

## Self-Submissions and Affiliation

Self-submissions are allowed, but contributors must disclose any affiliation with the submitted tool or website.

Affiliation includes being the creator, owner, employee, maintainer, affiliate, marketer, or otherwise directly associated with the project.

Being affiliated with a tool does **not** automatically disqualify it, but it also does not guarantee inclusion. The same curation standards apply to all submissions.

## Multiple Tools from the Same Website

To keep the list diverse and avoid turning it into a backlink directory:

- In most cases, one representative entry per tool suite or website is preferred.
- Multiple entries from the same domain may be accepted when the tools provide clearly distinct and substantial functionality.
- Large batches of similar pages from the same website are unlikely to be accepted.
- Maintainers may consolidate existing entries into a single website or suite listing.

## How to Add a Tool

1. Fork this repository.
2. Add your entry to the most relevant category.
3. Place the entry in alphabetical order within that category.
4. Use this exact format:

   ```markdown
   - [Tool Name](https://tool-url.com) - Short, factual description of what the tool does.
   ```

5. Keep the description concise, preferably under 120 characters.
6. Describe what the tool does, not why someone should use it.
7. Do not use marketing language, emojis, superlatives, or exclamation marks.
8. If the tool does not fit an existing category, open an issue first to discuss a new category.
9. Submit one pull request per tool unless a maintainer has requested otherwise.

## Description Style

Good:

```markdown
- [Example Tool](https://example.com) - Convert JSON to YAML directly in the browser.
```

Avoid:

```markdown
- [Example Tool](https://example.com) - The best and fastest FREE JSON tool on the internet!
```

Descriptions should be neutral, specific, and easy to scan.

## Pull Request Checklist

Before submitting, confirm that:

- [ ] The tool is functional.
- [ ] Core functionality is free to use.
- [ ] No mandatory account is required for core functionality.
- [ ] The tool is not already listed.
- [ ] The entry is in the correct category.
- [ ] The entry is in alphabetical order.
- [ ] The description is concise and factual.
- [ ] The URL points directly to the tool whenever possible.
- [ ] The URL contains no affiliate, referral, or tracking parameters.
- [ ] I have disclosed any affiliation with the tool below.

### Affiliation

Are you the creator, owner, employee, maintainer, affiliate, marketer, or otherwise associated with this tool?

- [ ] Yes
- [ ] No

If yes, briefly describe your affiliation in the pull request description.

## What May Be Rejected

Submissions may be declined for any of the following reasons:

- Broken, abandoned, or non-functional tools
- Mandatory payment for core functionality
- Mandatory signup or login for core functionality
- Duplicate or near-duplicate entries
- Thin wrappers or pages with little practical functionality
- Landing pages that primarily promote another product rather than provide a usable tool
- Affiliate, referral, or tracking links
- SEO-focused or backlink-focused submissions
- Multiple substantially similar tools from the same website
- Marketing-heavy or promotional descriptions
- Articles, courses, directories, newsletters, or general resources rather than tools
- Bulk or low-quality submissions
- Tools that fall outside the scope of this repository

## Existing Entries

Inclusion is not permanent.

Maintainers may update, consolidate, move, or remove existing entries if a tool:

- Becomes unavailable or broken
- Starts requiring payment or mandatory signup for core functionality
- Becomes abandoned
- Changes purpose
- Is superseded by a better or more representative listing
- No longer fits the scope or quality standards of the repository

## Maintainer Discretion

Awesome Web Tools is intentionally curated.

Maintainers may decline or remove an entry even when it technically meets the minimum requirements if including it would reduce the quality, diversity, usefulness, or maintainability of the collection.

Decisions should focus on the merits of the tool rather than the contributor.

## Code of Conduct

Be respectful and constructive in issues, reviews, and pull requests.

Disagreements about categorization or inclusion are fine, but keep discussions focused on the tool, the repository guidelines, and the value it provides to users.
